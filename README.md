# SamsBlog

精简、自托管的 Astro 个人博客，以插画、手写文字和日常记录为主，提供文章、项目、留言、友链与匿名统计。

## 架构

单体 SSR，使用 Astro + Node standalone、SQLite + 手写 SQL；后台为原生 DOM，不引入客户端框架或额外状态库。

| 位置 | 职责 |
| --- | --- |
| `src/pages/`、`src/pages/api/` | 页面、文件式接口与输入边界 |
| `src/components/`、`src/layouts/` | 共用界面、页面结构与局部交互 |
| `src/lib/` | 内容查询、认证、Markdown、网络探测及动效工具 |
| `src/config/site.ts` | 可公开的站点内容、初始赞助名单和交互参数，含启动校验 |
| `src/config/server.ts` | 服务端环境参数及校验，秘密只读进程环境 |
| `src/styles/`、`public/` | 设计变量、分区样式与本地静态资源 |
| `tests/`、`deploy/` | 回归测试、Linux 服务、代理与备份模板 |

### 页面与内容规则

- 公开页面共用卡片、媒体及带底色的小控件使用 C2 连续曲率。SVG 四角遮罩复用同一八段三次曲线路径，中段随尺寸伸展；共用轮廓随 SSR 样式首帧成形，无脚本仍可见，尺寸变化不新增观察器，读者专用轮廓沿用原规则。背景、阴影与内容分层；封面和友链背景在静止容器内裁切，悬停缩放及模糊光效沿同一轮廓收束。保留既有圆头像和文字操作下划线，焦点不随背景裁切。
- 后台内容列表可直接添加或取消星标，即时保存；星标标题在首页、内容页与阅读页呈现金色波浪流光和更明显的呼吸起伏，适配深浅主题、暂停和减少动效。星标不改变排序、发布时间、编辑时间或草稿内容。长外链说明复用短记录的原位“展开／收起”，短说明直接完整显示；首页“换一条”和后台预览同步支持，外链标题仍在新标签页打开。
- 阅读正文永久启用舒适阅读，居中且上限860px，不提供退出按钮；1400px以上在右侧显示独立目录，较窄屏幕沿用正文上方折叠目录。目录分层显示标题，圆角底色跟随当前章节；横线长度按实际章节高度计算（含子章节），颜色填充表示阅读进度。字号、图片和字体改变排版后重新计算，无新增滚动条。正文约19–20px，阅读按钮、日期和提示约17–18px；阅读按钮支持粉色悬停，字体切换和继续阅读保留说明提示。文章默认使用系统字体，保留“切换艺术字体”按钮；手动字体偏好只作用于文章标题和正文，代码用等宽字体，本机保存并在首帧恢复。
- 首页顺序：Hero → 项目 → 最新内容（长文1篇、短记录2条、精选链接1条）→ 留言纸条 → 网站友链。无文章时省略文章区块，不填充示例内容。Hero 不显示 Scroll Down 提示；在宽高比至少4:3的窗口使用1920×1080 WebP（由原图沿62%垂直焦点裁切），竖屏沿用同图的响应式竖幅 WebP，原始 PNG 保留供已有文章引用。
- 顶部导航为首页、内容、关于、读者。`/content` 集中展示全部文章与年月归档；关于页依次展示联系、痕迹、赞赏、完整友链和网站统计。统计保留首次可见时的数字动画及有效访问后的实时更新。旧 `/about#articles` 自动转入内容页并保留筛选参数，`/links` 永久重定向到 `/#friends`。
- 公开页面之间复用原生跨页转场：整页柔焦淡出，新页就绪后清晰淡入；不再单独衔接封面，不人为延迟请求。暂停或减少动态效果时直接切换，不支持原生转场的浏览器正常导航。
- 项目由后台新增、编辑、隐藏和排序，首页先显示前4个可见项目，再通过“更多项目”展开。可编辑名称、地址、简介、关键词、状态及可选 GitHub 仓库。仓库仅用于提交日期，有限并发读取并复用缓存；返回前复核公开状态，失败保留已有日期，没有日期时省略。
- 项目背景使用按需加载的 Three.js 柱阵：87°俯视、正向排列、无描边的连续高柱地形。柱面保持纯色明暗，不使用表面纹理或贴图。背景层上下各延伸48–96px，滚动过程约45%入场、10%完整展示、45%退场，沿波峰逐柱进出；两侧提前入场、延后退出，中间更晚出现、更早收回。进入时以更强的指数缓动快速升起后放缓落稳，退出沿原进度加速收回；窄色带随进退扫过表面，无快速闪烁。上下使用大范围错落渐隐与局部模糊，配色接近当前页面背景，两侧较清楚，文字下方进一步降低可见度，深色模式额外降低整体不透明度。静止时轻微起伏，滚动时加强连续波浪，不代表真实 Token 用量。密度、视角、缓动、波动和帧率由 `siteConfig.projectTerrain` 校验，色板与虚化变量使用 `global.css` 的 `--terrain-*`。单批绘制，固定高度预计算，边缘与扫描强度在顶点阶段计算；静止时最多20帧，滚动与进退时最多30帧。手机降低密度和模糊强度；暂停或系统减少动效时静止，离屏和后台不持续绘制，WebGL 不可用时省略装饰。
- 文章自动保存为私有草稿，显式点击“发布”后才公开；编辑已公开文章时，草稿不会覆盖线上内容。可撤回为草稿；重新发布保留原创建日期，更新编辑日期。删除为软删除，退出公开列表、RSS、站点地图，详情返回404；后台可恢复。来源为原创／搬运，分类为杂谈／日志，分别保存。
- 首页写纸条表单与已发布便签复用 C2 连续曲率纸面，首帧成形，保留胶带与纸色，内容和焦点不裁剪。匿名留言提交后待审核，公开端展示最新60个已公开根线程及其公开回复；后台读取全部未删除线程，不按200条截断。回复显示实际昵称，可在后台独立审核、隐藏或删除；删除根线程同时隐藏其回复。昵称和正文按 Unicode 码点限制为2–24与2–500字符，空字符被拒绝。后台写入期间锁定对应表单，失败保留输入并恢复操作。
- 公开友链依次为星标、推荐、默认、失联；组内按最新 RSS 文章日期倒序，无日期置后，同日期按编号稳定排序。首页以循环景深卡组展示全部公开友链：中央卡清晰，左右后退缩小、淡化与轻模糊，沿用黄、橘、蓝、灰组色和夏日纸面，卡片轻微错角、背光随悬停渐入渐出；仅计数居中置于卡片下方，上下留白随内容收紧。卡内保留站名、简介、头像、背景、RSS入口及三态连通文字，合入该站最新文章标题和短摘要，取消右侧独立动态；无网址、日期和毫秒。每张停留2.5秒后，用0.5秒非线性缓动切换到下一整张，再停稳；停留阶段没有持续帧循环。可用拖动、触摸横滑、横向触控板和左右键切换，手动松开后保留惯性并自然减速归位，不拦截纵向滚动；滑动期间暂停，悬停不暂停，键盘正在操作卡片链接时保护焦点；离屏、后台、全局暂停或减少动效时停止自动切换；暂停或减少动效时仍可拖动、横滑和使用横向触控板，直接整张切换。每站仅一个卡片节点，刷新后排除已隐藏项再按原规则重排，并保持当前站点与交互焦点；交互参数由 `siteConfig.friendDeck` 校验，视觉变量位于 `global.css`。无脚本保留可访问的静态卡片。“全部友链”进入 `/about#friends`，保留原网格与分组标题；失联组为空时连同标题、空提示隐藏，状态及RSS刷新后同步收起或恢复，其余组保留空态。有效连通失败移至失联，恢复后回原标记组，未知或过期不判失联。后台推荐与星标独立保存，星标优先；隐藏和软删除不公开。
- GitHub 贡献由服务器内存缓存；已有快照过期时立即展示旧数据，后台刷新失败仍保留旧数据，进程冷启动没有快照时仍需等待首次请求。痕迹区块桌面同一行显示 GitHub、ChatGPT 用量和文章数量，窄屏纵排；文章总数实时统计已发布且未删除的长文章，热力图按北京时间的发布日期展示近一年分布，编辑不重复计数，删除／恢复同步生效。ChatGPT 用量汇总本机 CCswitch 全部应用与提供方的已核对快照，标题沿用现有名称；不自动读取访客或服务器上的 CCswitch。数据与日期在 `src/pages/about.astro`，缺失日期不按零用量补齐。全部年度图默认定位最新日期端，隐藏横向滚动条，保留滑动与方向键浏览；移除月份导航和“回到最新”，初次仍自动定位最新端。
- 页脚底部留白为28px，右侧 RSS 旁提供 Status 外链，在当前页打开 `https://status.moesam.com`。页脚延迟位于 © SamsBlog 右侧，没有圆点；页脚实际进入视口后才开始采样，后台或窄屏隐藏时暂停新采样，检测失败隐藏，网络详情按需加载。320px及以下隐藏 SamsBlog 与延迟，保留签名、版本、RSS和Status并维持单行。点击 SuperSam 手写签名进入 `/admin`，不再单独显示“管理”入口，键盘聚焦有清晰提示。签名与版本号作为一组保持页面水平居中，版本读取 `package.json`。
- 赞助名单可在后台“赞助”区新增、编辑和删除，填写名称、累计金额及可选 Minecraft 用户名。按金额降序、同额按添加顺序展示；金额以分存储，删除沿用软删除，旧窗口不能覆盖新编辑。达到6人时名单分两列，手机窄屏保持单列。名字前展示 Minotar 的64px Minecraft 头像，含皮肤帽子／外层，用户名留空时使用名称；靠近赞赏区时预载，点击后等待头像解码完成再展开，超时或失败使用名字首字，不发送页面来源。

视觉、动效、移动端和无障碍要求集中在 [design/README.md](design/README.md)，协作与验证纪律见 [AGENTS.md](AGENTS.md)。

首页只加载共用文章样式；阅读工具、目录、图片查看器、摘录弹窗和评论样式在阅读页及后台预览加载。背景在既有柔和光晕上使用低对比 Silk，褶皱与缓慢流动更清楚，高光保持克制；原生 WebGL2 单次绘制，无新增依赖；`siteConfig.ambientSilk` 默认12fps与低分辨率，深浅主题独立配色。暂停、减少动效或页面隐藏时停止调度并保留静态，WebGL2不可用时回退既有光晕。首页独立移除大面积粉色光晕及内容区切粉逻辑，项目区保留蓝色、其余区块为中性；其他页面光晕及语义粉色沿用原样。粒子、星座连线及点击火花保持移除；原版权与 MIT + Commons Clause 许可全文保留于 [ambient-silk.ts](src/lib/ambient-silk.ts) 文件头。首屏字标与手机768px头图采用重新压缩的 WebP，尺寸与构图不变，桌面仍使用1080p头图；旧图片地址继续有效。开发模式显式预优化按需加载的 Three.js 与 Passkey 浏览器模块，减少预构建切换造成旧导入地址失效；Passkey 模块载入失败时提示刷新页面后重试。

首屏可见内容保持服务端输出，滚动渐入仅作用于屏幕下方内容。读者页面区域在同步写入连续曲率路径后立即显现；`siteConfig.readerPresentation.readyTimeoutMilliseconds` 默认2000，仅作为轮廓加载失败的截止时间，历史恢复立即释放，无脚本时保留无外框降级。

### 读者身份

Header 最右端的“读者”为普通链接，进入 `/reader`：未登录显示页内登录卡片，已登录显示账号页。导航身份由服务端输出，有头像地址时在文字左侧显示32px图片，无地址不占位，当前页面保留高亮。登录支持邮箱三位数字验证码（允许前导零）、BlogsClub、GitHub、Google 和 Passkey；未配置的提供方禁用。邮箱验证后自动注册，无需密码。验证码邮件包含 SamsBlog 品牌 HTML 与纯文本回退，突出验证码、配置有效期及简短忽略提示。读者会话独立于站长管理权限，不同方式不按相同邮箱自动合并账户。

邮箱登录分两步。可见登录区固定在视口内，页脚首屏可见；极矮屏或软键盘时允许主区内部滚动，账号长页仍正常滚动。一级保留邮箱、获取按钮与其他登录方式，增加区域留白并展示简短安全处理说明，现有隐私采集和存储边界不变。邮箱继续使用透明下划线及手绘竖光标，关闭自动补全、自动大写与拼写检查。

获取成功后才进入二级，去掉外层大卡片，仅显示放大的3个独立 C2 CodeSlots 数字框，以及无背景、阴影和外框的回退／确定文字操作。支持逐位输入、整码粘贴、数字键盘和系统自动填充，保留前导零。填满3位自动验证，确定按钮保留备用；同次输入只提交一次，错误及限速反馈居中，失败显示叉号后清空并聚焦首格，回退不重发，同一邮箱在冷却期内可继续验证。服务端确认成功后，三格合拢显示对勾，展示完成后再进入账号；暂停或减少动效时使用短暂静态反馈。验证按同来源与同邮箱各滚动60秒最多5次限额执行，限速提示不自动重试；原单码次数、有效期及来源／全站额度继续生效。动效时序由 `siteConfig.readerCodeSlots` 校验。

Google／BlogsClub／GitHub／Passkey 以两列等宽连续曲率胶囊排列，图标与文字各占固定列，整组居中、列内左对齐；BlogsClub 使用原创实心 B 单色 SVG（无外框或描线），文字沿用站内艺术字体。胶囊轻影贴合曲率，悬停字色平滑过渡，点击呈现 Material 式涟漪；暂停或减少动效时使用短暂静态反馈。登录成功后显示服务端账号页，退出后显示登录页。

OAuth 在点击时打开独立浏览器授权窗口，授权期间 `/reader` 保留当前位置和输入。完成页只提示原页面重新查询服务端会话，不传递身份、授权码或令牌；会话创建时间变化后才确认登录或同账号重验。窗口通信受限时继续查询，关窗不当作成功；支持取消与超时，失败后恢复控件和焦点。窗口尺寸、查询间隔及等待上限由 `siteConfig.readerPopup` 配置，默认520×720、3秒、10分钟。

账号页直接展示无外框、连续曲率轮廓与低对比半透明纯色层次的卡片，桌面加宽、小字放大，卡内保持紧凑，区块上下间距略增。登录方式图标徽标位于注册时间左侧，保留名称的 `aria-label` 与 `title`；统计行最右侧为“退出登录”胶囊。可修改昵称、个人网站及回复通知邮箱，点击头像更换图片；头像悬停或聚焦时显示铅笔图标并虚化底图。编辑昵称需2–12个 Unicode 码点，修改同步既有署名，旧长昵称保留可读。头像仅接受 JPEG／PNG／WebP／GIF，文件不超过2MiB；更换后保留旧图，共用或仍被读者引用的头像禁止后台删除。可管理 Passkey，查看注册时间、累计留言与评论次数及本人留言分页；隐藏文章不返回标题或跳转地址。Passkey 添加和移除需15分钟内重新验证，移除需二次点击；过期时在同页切换到身份验证区域，也可返回账号，验证后自行重新选择操作。身份切换先清空旧资料。

回复通知邮箱默认空、可选，仅在自己的账号页和私有账号响应中显示；只校验地址格式，不用于登录或身份合并。登录留言与文章评论隐藏邮箱输入，勾选通知且发信已配置时由服务端读取账户邮箱，忽略客户端提交的邮箱；未设置时照常发表且不订阅。修改或清空仅影响之后新帖，既有订阅、已入队邮件与逐帖退订规则保持原样。

完整账号资料、Passkey 和首批本人留言均由服务端直接输出，客户端接管已有状态。保存资料原位反馈并保留等待期间的新编辑，不重复读取列表。

登录读者的称呼由服务端身份决定，提交后直接公开；首页留言与文章评论隐藏整行称呼输入，显示放大的身份提示，匿名访客保留称呼输入；登录或退出即时切换，并保留匿名草稿。匿名留言、评论和回复先审核，待审内容不会插入公开列表。两者都只能回复已公开父帖。登录邮箱不自动作为回复通知邮箱；匿名称呼和邮箱草稿继续保留。验证码、登录邮箱及账户回复通知邮箱不写入 localStorage；所有 HTML 响应使用 `private, no-store` 与 `Vary: Cookie`，静态资源和 RSS 沿用各自缓存规则。

### 文章与阅读

后台采用 Markdown 编辑，正文随输入、载入及插图自动向下增高，删减后缩回；桌面最低420px、手机最低320px，长文沿抽屉滚动。可切换阅读页实时预览与首页卡片预览；复用公开页的 Markdown 渲染、目录和 `ArticleCard.astro`。支持标题、列表、引用、代码、粗斜体、删除线、链接和图片；原始 HTML 转义为文字，不执行嵌入脚本。首图可选，支持公开图片网址或本地上传。搬运文章可独立填写原作者和原文链接。

每篇文章可选择左图右文、右图左文或纯文字；首页和内容页沿用同一布局，筛选重排不改变图片方向。旧文章默认左图右文；纯文字仅隐藏卡片图片，保留阅读页首图。布局由 SQLite CHECK 约束校验，删除与恢复保持原设置。首图加载失败只隐藏图像，公开卡片与后台预览均保留文本位置；未设置首图和显式纯文字仍使用全宽布局。摘要可手动填写；留空时复用 Markdown 渲染器提取文字，跳过整个代码块，保留行内代码和图片说明；正文不受影响。

内容形式独立于来源和分类：长文章保留横向封面，短记录展示日期与一段摘要，日期和归档标题可进入独立阅读页；点击日期旁的“展开／收起”原地阅读完整 Markdown，不离开列表；简单短记录能在摘要区域完整展示时省略展开按钮，随窗口宽度重新判断。首页、内容页归档和后台卡片预览共用高度过渡，暂停或减少动效时直接切换，无脚本时保留“阅读全文”链接。外部链接显示域名和引用条，更新记录使用紧凑时间节点。后台选择形式，首页卡片预览即时同步；外链额外填写完整 HTTP(S) 地址，外链标题在新标签页打开，阅读页与 RSS 保留说明和目标链接。四种形式共用题目、Markdown、标签、归档、保存和软删除流程；内容页支持按形式筛选。旧内容迁移为长文章，痕迹中的文章数量只统计长文章；不添加示例内容。

首页展示最新一篇长文，下方并列两条短记录（含更新节点）与一个精选链接，缺少内容时自动隐藏，手机改为单列。数量统一在 `siteConfig.articles` 的 `homepageCount`、`homepageNoteCount`、`homepageLinkCount` 配置；数据库按类型和日期索引限量读取，不让短记录挤走长文。长文卡片使用紧凑的上下留白并保留两行摘要；精选链接不显示左侧竖线，来自后台发布的外部链接，不额外抓取目标网站。

首页字标随原生滚动时间线轻退场，正文仍正常滚动进入；浏览器不支持时保持静态。字标、搜索和跳转按钮只在操作时反馈，内容内层复用现有一次性可见性观察。首页、内容、关于与文章页统一采用整页柔焦淡出和清晰淡入，不再拆分导航、正文与封面快照。没有新增动画依赖、Canvas 或持续帧循环，暂停和系统减少动效立即呈现内容。

局部动效共用 `--ease-spring`：支持时使用原生 CSS `linear()` 短回弹，旧浏览器回退贝塞尔曲线；字标、菜单图标和选中标记共用曲线。手机筛选在原位置展开和收束，搜索状态与结果数量在文案变化时短暂接入。复制成功显示粉色文字和确认勾；提示浮层以触发位置为中心首次出现，连续浏览热力图日期立即更新，不重复入场。

内容页支持题目、手动摘要与 Markdown 正文全文搜索（含代码文字）；“全部／归档”位于右侧筛选顶部，下方依次为排序、形式和星标；桌面筛选固定于浏览器视口，滚动到页顶、中段或页底均保持可见；避开顶部导航和正文，低高度时区域内部可滚动；手机“全部／归档”常显于筛选折叠入口上方，排序、形式和星标仍在原位折叠，搜索展开不隐藏视图切换，筛选项悬停不位移，不显示筛选底部的重置按钮。旧 URL 中的来源、分类、标签和发表年月继续生效，当前条件在列表上方显示并可重置；星标、形式与搜索、归档及旧条件组合，保存在 URL。标题旁“搜索”在同一行向左展开无底板的手写输入栏，点击收起、外部或 Escape 关闭；保留关键词时入口变为红色“取消”，点击仅清空搜索，其他筛选不变。动效适配暂停与减少动态效果，搜索与留言共用短手绘光标，保留原生选区和中文输入法。归档按北京时间的发表年月分组，组内沿所选排序，文章保持公开。列表与归档复用同一套卡片，筛选规则集中在 `src/lib/article-catalog.ts`。

后台可新建和选择多个 `#标签`，点击已选标签移除；默认每篇最多8个，每个24个 Unicode 字符，限制位于 `siteConfig.articles`。标签按兼容字符规范化、忽略大小写去重，与来源／分类独立保存。SQLite 增量迁移为旧文章填充空标签，创建日期和正文保持不变；软删除与恢复保留标签。阅读页的标签可跳回内容页筛选。

用量快照已按本机 CCswitch 记录更新至北京时间2026-11-07 01:38，包含全部应用、模型和提供方，统一显示在“ChatGPT 用量”。公开页仅显示“截至 2026-11-07”，不显示来源前缀或当日未完提示；既有数值与快照截止时间不变。按输入语义归一化，区分缓存命中、未命中与输出；缓存创建计入未命中，避免缓存再次计入输入。日汇总与逐请求记录按应用核对日期及来源后合并；已有日期覆盖，新增日期补入，不与旧快照叠加。本次同应用的新旧数据日期无重叠，也不存在同应用代理与会话记录混用。

正文可直接粘贴剪贴板图片；上传期间可继续编辑，中文组词确认后才插入，成功后插入跟踪到的原位置，切换草稿后不误插入，失败保留正文，未完成上传时暂不发布。媒体库列出文章和草稿中的首图／正文引用，独立媒体页也可直接进入文章抽屉并定位，已删除的引用先恢复再编辑。编辑器的“上传首图／上传图片”直接选择本地文件；后台“媒体库”支持预览、按名称搜索、插入正文、设为首图、复制地址和回收站恢复，不刷新文章草稿。支持 JPG、PNG、WebP、GIF，默认单张10MiB，保留原图；文件按内容哈希去重，存到 `$BLOG_DATA_DIR/uploads/`，元数据存 SQLite。上传即获得公开图片地址，文章仍需点击发布才公开；不会随构建覆盖。已被文章引用的图片（包括已删除文章）不能删除，自动保存的草稿也参与服务端引用检查，当前未保存草稿在界面阻止误删。服务端按 Markdown 实际渲染的同源地址识别引用，包含编码路径和尖括号地址。软删除停止公开访问但保留文件，可恢复；不提供永久清理按钮。

文章和项目的未保存修改在站内跳转、退出及其他分区触发刷新前统一确认；切换文章单独确认当前文章。页面准备离开后锁定编辑，其他分区仍在写入时暂不离开，避免等待期间的新输入被刷新。后台文档禁止缓存。文章停笔1.8秒后自动保存到服务器，中文输入法组词时不保存半成品；也可手动保存。以“草稿已保存”反馈为准，尚未完成的请求不保证在关页后继续。草稿版本冲突保留当前输入，防止旧窗口覆盖；草稿删除可恢复。

后台与留言共用 JSON 请求截止处理，默认15秒，覆盖连接及响应体读取。失败或超时保留输入并恢复操作；超时提示结果尚未确认，不自动重试写入。留言与后台日期统一按北京时间显示。

阅读页提供舒适阅读、唯一标题锚点、自动目录、相邻文章、图片查看器、代码复制与换行。无链接图片和指向自身的单图链接可放大；图片指向其他网页时保留作者的导航，不覆盖链接名称。查看器支持 Escape、焦点返回和手机系统缩放。长代码默认约16行高度，可展开／收起；工具条吸顶，代码横向滚动不带动页面。围栏可写 `ts title="src/example.ts"`、`ts filename="src/example.ts"` 或 `ts src/example.ts` 显示文件名。复制保留完整内容和原始缩进，不包含文件名，成功显示粉色“复制成功”。

### 后台、评论与回复通知

后台 `/admin` 概览直接展示7／30／90天浏览、访客、趋势与文章排行，移除工作台入口网格和重复的统计导航；旧 `/admin/analytics` 地址继续可用。登录入口的标题、说明、密码标签、输入框、按钮与状态提示使用放大后的字号，手机不再额外缩小说明文字；不影响编辑工作区字号。内容、媒体、评论与留言、友链、友链申请、项目、赞助、回复通知分别拥有独立地址。列表保留在主区域，新建、编辑、审核在右侧抽屉完成；手机使用全屏抽屉，标题固定、正文独立滚动，Escape 与关闭按钮恢复焦点。媒体页可独立上传、复制和回收图片，插入正文与设为首图仅在文章编辑器中提供。

申请友链弹窗与后台抽屉共用 CSS 时长换算，兼容秒和毫秒；生产样式压缩不会改变进退动画时长。

匿名文章评论与首页留言先审核，已登录读者使用服务端身份提交；后台可隐藏和软删除。每篇文章隔离根评论与一级回复，隐藏父评论后回复也不公开。“喜欢／有帮助／有启发”位于 COMMENTS 标题区右上角，窄屏自然换行并保持右对齐；每个匿名浏览器对同一文章保留一项，可切换或取消。邮箱和匿名指纹不出现在公开接口。

留言与评论输入框随内容增高，最多8行，删减后缩回；`Ctrl + Enter` 提交，普通 Enter 换行，输入法组词及确认键释放前不会误提交。颜文字提供10个精选选项，在当前光标或选区插入，最近6个仅保存在本机；展开与收起使用非线性高度和透明度过渡，暂停或减少动效时立即切换。长留言／回复可展开全文，每组先显示3条回复，其余展开查看；后台身份的回复使用页脚同款 SuperSam 手写标识，不根据昵称判断。

文章评论中选中不超过180字的原话，再点击该条“引用回复”，表单显示原话和对象。服务器确认引用来自同一文章的公开评论；源评论或所在根线程隐藏、删除后，不再公开旧引用。提交期间继续输入的文字保留，成功后新回复所在折叠组自动展开。

留言和评论直接显示邮箱与手绘勾选框，“记住称呼和邮箱”和“收到回复邮件通知”默认勾选。提交成功后在本站 localStorage 保存称呼和邮箱；取消记忆立即清除资料，并保留关闭记忆的选择，不显示清除成功提示。不记忆正文或通知授权；未填邮箱时正常留言，不订阅通知；邮箱仅在勾选通知且填写邮箱时传给服务端。未配置发信服务时不显示通知选项。

文章访问概览提供7／30／90天有效浏览、去重访客和文章排行。页面在前台连续停留10秒后才确认一次，隐藏／离开取消计时，回到前台重新计时；后台、已登录站长、已识别机器人和预加载不计入。同一匿名浏览器同一页面30分钟内只计一次，跨页分别计算；查询参数不制造新页面。去重时间由 `ANALYTICS_DEDUPLICATION_SECONDS` 配置（默认1800，最多86400秒），前台时间位于 `siteConfig.analytics.visibleMilliseconds`。关于页确认后更新网站统计数字，不必再刷新。新口径使用独立统计表，从升级后起算；旧 `site_visitors` 和 `article_daily_visitors` 数据保留备查，不混入新数字，也不猜测修正历史。统计保存匿名 Cookie 哈希和最近关联的读者编号，不存 IP、UA 或访客邮箱；同一浏览器跨天计入总访客一次，清除 Cookie 或更换设备会重新计数。禁用脚本、禁用 Cookie、拦截统计请求或停留不足10秒会漏计；这是有效浏览估计，不是精确人数或防恶意刷量系统。

后台统计新增访客记录：匿名短编号、累计有效访问、首次／最近访问和最近关联读者名，支持“最近访问／累计次数”排序及分页。累计访问不随文章7／30／90天筛选变化。最近关联来自已登录访问确认，去重请求也可更新关联，但不增加次数或归并历史；退出后仍保留最近关联。不展示或推测真实个人身份，公开统计接口不返回访客明细。

2. 在 [Resend Domains](https://resend.com/domains) 添加并验证 **moesam.com**。只启用发送，逐项照当前控制台添加 DKIM 与发送验证记录；不同发送通道可能使用 MX／TXT 或 CNAME，不要混套旧教程。CNAME 使用 DNS Only；名称和值以控制台为准。等待域名显示 Verified，DNS 可查询不等同于 Resend 已完成验证。根域 MX 保留 Cloudflare 等现有转发服务的记录。
3. 同一主机名只保留一条 SPF；与转发服务已有的记录冲突时合并授权，不能再新建第二条。原网站 A／AAAA／CNAME 保持不变。按服务商指引补充 DMARC。
4. 在服务器环境文件设置 `RESEND_API_KEY`、`MAIL_FROM=blog@moesam.com`、`MAIL_REPLY_TO=blog@moesam.com` 和已有的至少32字符 `BLOG_SECRET`。需要站长提醒时增加 `MAIL_ADMIN_TO=实际收件邮箱`，留空则关闭。密钥只存服务端，不填到文章或前端。
5. 在 [Resend Templates](https://resend.com/templates) 创建并发布模板，分别将 ID 或别名写入 `RESEND_REPLY_TEMPLATE_ID`、`RESEND_ADMIN_TEMPLATE_ID`。当前模板别名为 `samsblog-reply-v1`、`samsblog-admin-v1`；可直接在 Resend 修改文案和排版后 Publish，保留现有变量名。模板 ID 留空时使用代码内同款信纸；单个变量超出服务商2000字符限制时也使用完整 HTML，不截断留言。模板定义由 `src/lib/reply-email.ts` 的 `createResendTemplate` 生成，云端后续修改不会自动覆盖本地后备模板。
6. 部署代码及 `public/media/branding/mail-*` 图片并重启博客；邮件与图片链接使用 `siteConfig.rss.siteUrl`，应可从公网访问。先用 Resend 官方 `delivered@resend.dev` 测试地址验证模板，再用自己授权的测试邮箱验证实际收件。服务商接受请求只记为“已提交”，不等同于已经到达收件箱。免费转发没有个人邮箱收件箱或 SMTP，本方案只承担博客通知与收取回复。

通知共用持久队列，超时／429／5xx 退避重试，默认最多5次；首次投递前保存请求正文，重试复用正文和幂等键，超过23小时不再重试。原回复队列迁移时保留 ID、状态与请求快照。服务重启后首次请求恢复队列。访客回信发送前重新核对评论、文章公开状态和通知授权；先回复再审核公开的留言会补排通知。访客回信附签名退订链接，退订清除该评论的邮箱与订阅；完成、取消或永久失败时清除请求正文。已经交给发信服务的邮件不能撤回。API 密钥尚未配置时不会实际发信。官方设置说明：[Resend 验证域名](https://resend.com/docs/dashboard/domains/introduction)、[发布模板](https://resend.com/docs/api-reference/templates/publish-template)。

两套邮件采用米白星空信纸，左上角为 SamsBlog 字标，右侧链接 moesam.com，边缘使用稀疏星点与粉蓝光晕。访客回信同时显示原留言和回复；站长回复使用页脚 SuperSam 手写笔迹的静态图片，访客回复保留实际昵称。正文是可复制的 HTML，并同时提供纯文本；屏蔽图片时仍可阅读、查看回复和退订。颜色取自 `global.css` 的 `--mail-*`，静态装饰位于 `public/media/branding/mail-*`；邮箱客户端可能替换字体、颜色或忽略背景图。

站长提醒仅针对启用后收到的新留言、文章评论、访客回复和友链申请，附对应后台入口，不补发历史记录。后台自己回复不通知自己；发送前已隐藏／删除的留言或已处理的友链申请自动取消。访客是否订阅回信不影响站长提醒。后台“邮件通知”显示访客回信、站长提醒和“友链通过回信”的排队、已提交或失败状态，并提供 Resend 模板管理入口。

### 订阅与跨站数据

`/rss.xml` 每次请求读取最新20篇公开文章，`description` 输出摘要，`content:encoded` 输出首图与完整正文。频道为 SamsBlog，简介为“只是一只大黄狗”，公开地址在 `siteConfig.rss` 配置为 `https://blog.moesam.com/`，本地预览也不会输出 localhost 文章链接；主题名称与版本取本站名称和 `package.json`。发布、撤回、编辑、删除、恢复后自动更新，无需生成文件；订阅器决定拉取频率。站内链接和图片转为完整网址。阅读页输出专属 Open Graph、发表／编辑时间与 `BlogPosting`。

页脚 RSS 提供订阅说明、地址复制及原 XML 入口，禁用脚本时直接打开订阅源。浏览器直接打开 `/rss.xml` 时显示蓝色标签、粉色属性的彩色源码，自动换行；订阅器仍收到标准 XML，`/rss.xml?raw` 始终返回原始 XML。根据 `Accept` 与 `Sec-Fetch-Dest` 区分响应并设置 `Vary`，不依赖 XSLT 或执行正文 HTML。首页每张友链卡内展示该站最新一篇 RSS 文章标题和纯文字短摘要，标题打开原文；无有效条目时省略，不复制卡片内容到外部区域。首屏读取已有缓存，接近友链区后刷新，不阻塞首屏。友链 RSS 在服务器按需刷新并持久缓存30分钟；刷新失败保留同一订阅的有效旧条目，换地址后不复用旧缓存，缺失日期省略。

跨站卡片 `/api/public/site-card.json` 提供最新3篇文章摘要，允许 `https://moesam.com` 跨域读取；缓存5分钟，外站接入不在本仓库内实现。

## 使用与配置

### 阅读与局部交互

- 首页精选链接的“换一条”按发布时间循环切换公开外链，跳过软删除内容，始终只显示一个；失败保留当前卡片并给出提示。
- Markdown 引用区块右上角提供“摘录成卡”，直接用该段引用在本机生成带文章标题与地址的 PNG；最多450字，沿用本站字体和当前主题；背景为干净底色与边缘蓝粉主题光晕，文字区域减淡装饰；浅色中央保持清透，深色光晕更克制，落款复用导航 SamsBlog 字标图片。只绘制静态 PNG，不上传文字、不请求外部制图服务。
- 内容页文章列表上方显示本机最近2篇阅读路径，无标题、无清除记录入口；首页不显示阅读路径。复用已有断点，最多保留50条本机记录，不显示清除按钮；已有记录继续读取和同步，已删除文章不展示，文章编辑后不恢复旧版本进度。
- 首页进入项目区时背景光晕偏蓝，进入内容区时偏粉，沿用区块导航的位置判断并自动完成颜色过渡。
- 留言成功后纸条折叠、盖上“已收到”印记，再恢复空白纸条；提交期间的新输入与中文组合输入仍保留，不触发折叠。
- 页脚保留 SuperSam 的1秒手写签名与版本号，不添加琴弦装饰。减少动效时签名和留言成功文案直接显示。
- 导航 SamsBlog 字标使用低透明度的蓝、绿、金、粉、紫虹彩与鼠标轻倾斜，不采用叠亮混合，不加载 Three.js。触摸设备不保留悬停，暂停或减少动效时关闭位移。
- 站内链接与友链均保持普通跳转，不使用悬停预览。

后台 Markdown 工具栏可插入“展开解释”、“旁注”和“剧透”，实时预览复用阅读页渲染。也可直接编写：

````markdown
:::details 为什么这样设计？
这里可以写 **补充解释**、链接、列表和代码。
:::

:::aside 一点补充
宽屏放在正文右边，手机放回文中。
:::
````

无 JavaScript 时解释与剧透仍可展开，旁注仍可阅读；原始 HTML 继续转义。剧透不进入自动摘要或目录，RSS 用原文查看提示代替剧透正文；其余解释与旁注保留完整内容。剧透属于阅读遮挡，不是内容访问权限。

## 接口契约

写接口使用 `application/json` 与顶层对象；ID 是正整数，布尔字段使用 JSON 布尔值。错误为 `{error:中文消息}`；成功通常200，创建201。所有 `/api/admin/` 内容接口都复核会话，登录除外。

| 路由 | 方法／权限 | 契约 |

## 数据与部署

公开写入按来源 IP 的 HMAC 指纹计数，不保存完整 IP。友链申请在滚动一小时内最多成功 2 次；留言和文章评论在滚动一分钟内合计最多成功 2 次，超额返回 HTTP 429，不入库、不排队发信。配额由 SQLite 中已接受的记录计算，服务重启不清零。旧的 `MESSAGE_COOLDOWN_SECONDS` 和 `FRIEND_APPLICATION_COOLDOWN_SECONDS` 不再生效。

反代入口对两条提交路径的 POST 另设按 IP 和全站突发限流，具体参数见 `deploy/nginx.conf`；GET、缓存资源和管理路由不计入。使用 Cloudflare 时，可另设按 IP 的短窗口限流，仅匹配博客这两条 API（套餐不支持 Method 时按路径匹配）；边缘层不是精确小时／分钟配额。Tunnel 回源时，Nginx 仅从本机可信连接读取 `CF-Connecting-IP`，并重写传给应用的地址头；不得信任客户端自带的转发头。

数据库为 `$BLOG_DATA_DIR/blog.sqlite`，使用 WAL、外键和 CHECK 约束。迁移在启动时按记录增量应用；新文章使用 `blog_articles`，不读取或自动发布退役的历史文章／相册表，也不在启动时删除历史表。保留数据库及备份目录。读者账号迁移兼容草稿版本已有字段与旧 OAuth 校验字段，保留账号、会话和通行密钥，避免重复加列导致页面无法打开。

域名迁移遇到友链地址冲突时，优先保留已使用新域名的记录，其余记录软删除并保留原编号、内容和缓存后迁移；不会覆盖新记录的编辑内容。冲突记录不能直接恢复为重复地址。首页、RSS 和跨站卡片按所需数量查询；站点地图与相邻文章不读取全部正文。

Linux 部署流程：

1. 安装 Node.js 22.12+、pnpm、Nginx 和 SQLite CLI；创建 `samsblog` 用户及 `/opt/samsblog/shared/data`，仅授予必要的数据目录写权限。
2. 源码放到 `/opt/samsblog/current`，配置 `/etc/samsblog.env`，使用绝对 `BLOG_DATA_DIR`。不复制 Windows 的 `node_modules`、本机 `.env` 或旧构建产物。
3. 加载生产环境后执行 `pnpm install --frozen-lockfile` 与 `pnpm build`。`PUBLIC_SITE_URL` 必须匹配实际 HTTPS 域名；将构建输出和 `public/` 静态资源作为同一版本发布，包含首帧脚本。
4. 安装 `deploy/samsblog.service`。核对 `command -v node` 与 `ExecStart`；修改数据目录时同步修改 `ReadWritePaths`。服务以生产模式、专用用户运行。
5. 配置 `deploy/nginx.conf` 的域名、HTTPS 与 HTTP 跳转。模板按单层代理重写来源及 Host/Proto/Port 头，清除伪造地理头；Nginx 与 Node 请求上限11MiB以容纳图片和表单，JSON 接口仍按实际字节限制默认1MiB。已有服务器需同步调高 `client_max_body_size`，否则较大图片会收到413。多层代理需重新确认可信链。
   `/_astro/` 构建资源启用 gzip，并按 `Accept-Encoding` 区分缓存；仅压缩 CSS、JavaScript 等文本资源，不重复压缩图片。现有站点需同步此配置并通过 `nginx -t` 后重载，应用代码更新不会自动启用。
   v1.8.2 按 URL 规范保留默认端口为空，避免 HTTPS 转发域名被误判为不可信、同源上传返回403；仍限制协议与域名并保留跨站检查。
6. 安装 `deploy/backup.service`、`deploy/backup.timer` 为 `samsblog-backup.service`、`samsblog-backup.timer`。先手动备份并验证恢复，再启用计时器。
7. 验证健康、站点地图、真实 Cookie/CSP、后台写入与恢复、文章进入／返回的整页虚化切换，并核对日志和文件权限。仅重启博客服务。

备份固定在北京时间每天11:20执行，计时器显式使用 `Asia/Shanghai`，不依赖服务器本地时区。`deploy/backup.sh` 默认写入数据目录的 `backups/`，可配置 `BACKUP_DIR` 与正整数 `RETENTION_DAYS`（默认14）。备份先完成 SQLite 在线快照及完整性校验，再原子发布；成功后仅清理达到保留时长的 `samsblog-*.db`，不清理无关文件。脚本使用 Bash，部署文件保持 LF。

恢复前停止博客，保留当前数据库及 `-wal`／`-shm` 旁文件。用已校验备份恢复 `blog.sqlite`，启动前移走旧旁文件并恢复所有者权限，再验收业务数据。不得在运行中直接覆盖数据库。

`backup.sh` 只备份数据库。使用媒体库后还需备份整个 `uploads/` 目录（包含回收站文件）；迁移或恢复时同时恢复数据库和图片目录，不能只复制 `.db`。文件使用稳定内容地址，增量同步即可，不写入 Git。

## 安全边界

- 管理会话为签名、到期校验的 HttpOnly Cookie，SameSite=Strict，生产 Secure。每个管理接口独立鉴权；所有管理写操作统一检查同源 Origin，登录也先检查来源。Astro 来源检查、JSON 类型约束与 Strict Cookie 共同限制跨站写入，不开放管理 CORS。
- 图片上传还要求同源 Origin，按实际字节限额并识别文件签名，仅服务四种栅格图片，拒绝 SVG/HTML；原始文件名只作后台展示，不用于存储路径。图片响应带 nosniff 与重新校验缓存，回收站预览禁止缓存。原图不转码、不移除照片元数据。
- 写入表单显式使用 POST，提交按钮在各自脚本初始化后才启用；禁用脚本时显示说明，密码与正文不会通过原生 GET 提交进入网址。
- 密码使用异步 scrypt；来源及全站登录限速在解析正文前执行。管理写操作默认全会话共享120次／分钟，读取不受此额度影响。留言、申请、表态和浏览确认默认每来源共享60次／分钟请求额度，包含无效正文；更换匿名 Cookie 不会重置来源额度。以上均为单进程内存初级限速，重启会重置，不宣称抵御分布式流量攻击；成功留言／评论和友链申请另受持久化提交配额约束。
- 来源额度只保存哈希，直连请求使用连接地址；仅回环代理连接接受转发来源，部署必须由可信代理重写来源头并限制 Node 公网访问。公开来源表满时拒绝新来源，不通过逐出旧来源放宽限制。
- 统计持久化匿名 Cookie 哈希及最近关联读者编号，留言来源仅存哈希指纹，不存完整 IP/UA。访客 Cookie 在公开配置地址或实际请求为 HTTPS 时设置 Secure，不依赖客户端转发头，保留纯 HTTP 本地开发。成功的公开 HTML 请求只设置匿名 Cookie，不直接计数；前台停留后通过同源限体积接口确认，服务器按浏览器与页面事务去重。统计请求失败不影响页面，也不自动循环重试；Cookie 清除或机器人识别误差会影响统计。
- 友链探测与订阅只接受80/443端口，每次跳转重新验证并固定公网 DNS 地址，拒绝内网、回环、保留及混合解析地址。探测仅读响应头；订阅限制字节、深度、条目、并发、超时，拒绝 DTD、外部实体和压缩／截断响应。
- Markdown 转义 HTML 并限制链接协议；结构化数据转义危险字符。图片由浏览器直连，不填写带鉴权参数或私人资源的网址。
- Nginx 模板关闭常规访问日志，但错误日志和上游服务仍可能记录地址；真实 TLS、代理、CSP、系统权限、备份恢复须在部署环境单独验收。
- 安全响应头统一由 Nginx 设置：页面、接口、静态资源与错误响应包含 `nosniff`、`X-Frame-Options: DENY`；实际 HTTPS 连接才发送一年 HSTS，不启用 `includeSubDomains` 或 `preload`。模板的 `map` 放在 `http` 层，启用 TLS 后保留相同规则；应用现有 CSP 原样透传。更新代码不会自动修改线上 Nginx，需同步配置并执行 `nginx -t` 后重载。

深色保留 `:root` 原色板；浅色只在 `[data-theme="light"]` 覆盖画布、纸面和阴影，使用更清透的独立粉蓝／淡杏 `--glow-*` 光源。友链浅色背光与文字组色分开，文字强调色保持对比度；不提高全站光效强度，不改变深色色板。背景使用宽范围柔和位置渐变，浅深主题各沿原粉蓝杏色板，装饰光晕强度降低四分之一；仅保留几乎不可察的背景颗粒，没有水纹环、纤维线或条纹，不覆盖正文和图片，不接收点击或新增帧循环。右侧导航与项目悬停另设浅色变量；动效开关提示沿用左侧联系方式的宽度展开与透明度过渡，暂停或减少动效时直接显示。

域名现为 `moesam.com`，博客为 `blog.moesam.com`。启动时一次性迁移数据库内旧域名的友链、文章正文及图片、项目和站点设置，保留子域名与路径；历史内容日期不变。部署时还需同步 DNS、TLS 与反向代理域名配置。
