# 视觉与交互规范

记录当前界面契约；使用、配置与部署见根 README。视觉建议不等于已实施功能。

## 视觉基础

- 沿用夏日插画与粉、蓝、米配色，深浅主题共享字号与间距层级。光效使用独立 `--glow-*` 色板：浅色使用明亮粉蓝与淡杏色，文字继续使用深色强调色；自定义组件色的光效在浅色下混白，深色保持原值。
- 设计变量集中于 `src/styles/global.css` 的 `:root`，沿 `--bg/--surface/--text/--line/--ease-out` 命名；复用 `--playful` 字体栈，不下载新字体。
- 公开页面统一整页短柔焦退出、清晰淡入；不单独连接首图，不拆导航与正文快照。模糊范围沿用3px，切页时不叠加区块渐入；主题水波独立处理，暂停与减少动效跳过转场。
- 区块英文标题用单个词；正文、表单、统计和后台保持统一可读性。交互以文字、图标、柔和背光和轻微位移为主。
- 复用现有组件与 SVG，不叠加无关装饰或引入视觉依赖。

## 区块契约

- 首页顺序：Hero → 项目 → 内容 → 留言 → 友链 → 统计。内容先显示最新一篇长文，下方两列分别为最多两条短记录（含更新节点）与一个精选链接，空组隐藏、手机单列；复用公开卡片，不加外围面板。顶部导航为首页、内容、关于；桌面右侧为区块导航，手机隐藏。
- Hero 保留蓝白字标、厚度阴影、柔光和底部渐变。浅色主题的底部滚动提示使用深色字；插画上方导航使用独立浅色强调，离开首屏后恢复页面主题色，不全局反转媒体文字。项目桌面双列、手机单列；关键词使用同色手写双横线，悬停与键盘聚焦时绘制，离开反向收回。
- 项目背景为87°俯视、无旋转的连续柱阵，柱体贴合、无描边，颜色接近深浅主题背景，两侧保持主要能见度，中间保持柔和明暗，深色模式整体更淡。柱面保持纯色明暗，不使用表面纹理，配色随主题变化。背景层上下各延伸48–96px，沿波峰逐柱进出：滚动约45%入场、10%完整展示、45%退场。两侧提前入场、延后退出，中间更晚出现、更早收回；进入以更强的指数缓动快速升起后放缓，退出按原进度加速收回，窄色带随进退扫过，不使用快速闪烁。上下以大范围错落渐隐和局部模糊融入页面，模糊仅作用于柱阵，文字保持清晰。静止轻微浮动且最多20帧，滚动和进退时最多30帧，连续波浪增强；接近区块才加载 Three.js，暂停／减少动效时静态呈现，离屏／后台停止绘制。
- 内容页文章卡片纵向单列、无外框，摘要两行；长文卡片上下内边距12px，压缩标题、标签与摘要的纵向间隔；首图方向按每篇后台设置，支持左图、右图和纯文字，旧文章默认左图，图片朝正文渐隐。内容标题与文章整体增加顶部留白。标题右侧并排文章／归档与小号搜索入口；搜索在同一行向左展开，只有艺术字体和短手绘光标，无浮层、底板与外框。收起时有关键词则显示红色“取消”，只清空关键词；输入展开时手机暂时收起文章／归档入口以留足输入宽度。排序、来源、分类、星标、标签和折叠年月仍在右侧，手机折叠；标签默认显示使用最多的三个，其余以无边框入口展开；归档按月分组。筛选保存在 URL，阅读返回保留来源和位置。
- 后台阅读预览显示题目、来源、分类、标签、日期、首图、目录与正文；首页卡片预览直接复用公开卡片组件。顶部移除“媒体库”快捷按钮，媒体管理与上传入口保留。
- 内容形式使用同一套卡片结构：长文章沿用横向封面，短记录以粉色日期引出文字，简单内容可在摘要区域完整显示时不展示操作，较长记录在日期旁用无边框“展开／收起”原地切换摘要和全文，复用非线性高度动画，正文链接与图片保持可用；键盘可操作，无脚本降级为独立阅读链接，暂停和减少动效直接切换。外部链接使用蓝色域名与紧凑文字，不加左侧竖线，更新为杏色时间节点，日期与正文之间不加竖线。没有外框，沿用柔和背光；展开短记录不随悬停位移，归档仍可从标题索引原地展开。形式选择和外链地址在后台编辑，预览与公开列表同步。
- 外链说明复用短记录展开，按钮沿用外链蓝色，摘要能容纳的简单内容不显示按钮；展开正文中的链接独立可用，标题继续打开外部站点。首页轮换保留同一卡片节点并重置展开状态。
- 星标按钮在后台内容行内，无外框，以描边星形与淡金色区分状态；公开标题仅在字形内呈现金色流光，5.2秒波浪式流光与增强呼吸，浅色用较深金色保证可读性。暂停或减少动效后保持静态，不改变卡片布局与排序。
- 阅读页提供目录、代码复制与换行、图片对话框和主动恢复位置，进入及返回统一使用整页虚化切换。字号18–26px与标准／宽松行距集中在原有工具栏，使用无边框文字按钮和粉色选中反馈，本机记忆并首帧恢复；不跟随舒适阅读切换而重置。图片查看器加载时保留工具栏，失败显示就地重试，关闭和重新请求均清理旧加载。
- 剧透沿用正文解释的圆角折叠行与高度动效，以淡粉提示区别；默认收起，可键盘揭开，禁用脚本仍可使用；不把隐藏内容的标题带进目录，摘要和订阅正文以查看提示代替。
- 留言与评论输入框自动增高到8行，继续保留短手绘光标和原生选区。颜文字入口为无外框文字，可展开精选与本机最近使用；快捷键提示不抢占输入位置。长内容和超过3条的回复以明确文字入口折叠，站长标识复用一份静态签名字形，昵称相同的访客不显示此标识。引用原话在提交前和回复列表中使用淡蓝圆角底，无左侧竖线。
- 首页友链桌面为左侧3行2列，右侧是朋友最新RSS动态：按日期倒序显示标题、来源和原文链接，无外框、无新增持续动画；960px以下上下排列，620px以下单列。未取得内容时省略动态；静态缓存优先，接近区域再更新。
- 文章正文居中，上限1120px，舒适阅读860px；1400px以上右侧独立显示分层目录，当前章节以移动的圆角浅蓝底色提示。章节下方细线长度表示相对篇幅，填充表示阅读进度；图片、字体与模式变化后更新。窄屏仍用正文上方折叠目录，不增加可见滚动条。正文19–20px，工具及提示17–18px；阅读按钮均有粉色悬停和主题提示，可切换系统字体并记住本机偏好。
- 阅读补充解释使用无外框、淡蓝底的折叠行，原生 details 渐进增强为双向高度动画；旁注使用粉色小标题与轻细引线，1440px以上置于页边，窄屏回到正文流。正文引用使用无竖线的圆角淡色底块，右上角提供“摘录成卡”，直接摘取引用正文，沿用当前主题与艺术字体，PNG 背景复用页面的蓝粉边缘光晕、星点与少量连线，浅色保持明亮中心，深色压低色光，落款使用导航字标图片，正文下方装饰减淡，不叠加噪点或纹理；弹窗支持 Escape 与焦点恢复。
- 首页“换一条”与精选链接标题同行，依次循环公开链接，始终只占一张卡片；不自动轮播。内容页 CONTENT 标题下方为本机阅读路径，最多两条，首页内容区显示最近一条“之前读到”；标题悬停变色双向过渡，无记录时整行隐藏。
- 导航字标的蓝、绿、金、粉、紫虹彩只覆盖已有字形，透明度0.38，不用叠亮混合，停留时微倾斜；不扩张导航高度，无持续帧循环。站内链接与友链无悬停预览。
- 留言保留纸条、胶带与折角，列表内部滚动，底部渐隐随滚动解除。失败保留输入；成功仅清空仍等于本次提交值且未处于输入法组合中的字段，保留等待期间的新输入。清空后播放折纸、收件印记与空白纸条恢复，重新聚焦或输入立即结束装饰动画；暂停与减少动效时直接显示成功文案。
- 友链星标优先，同组按添加时间由早到晚；后台复用文章的无边框星标操作，公开名称与星号共用文章标题的金色波浪光效。首页友链最多6个，右侧无边框“全部友链”跳到关于页完整列表；关于页友链位于赞赏支持下方，右侧导航顺序与区块一致。共享紧凑卡片，仅当前悬停项轻微放大，其他项保持原尺寸，键盘聚焦保留清晰提示；触摸、暂停和减少动效不产生粘滞位移。友链背景减淡、虚化和羽化；名称后先日期、再 RSS，日期是不可点击的纯文本，仅 RSS 打开订阅地址，不展开文章、无箭头。缩小上下留白，窄屏允许自然换行；缺失日期仅显示 RSS。
- 关于页联系区桌面四列、中屏两列、手机单列。痕迹桌面同一行依次显示 GitHub、ChatGPT 用量、文章数量，窄屏单列；三张热力图顶端对齐，分别使用蓝、粉、杏色。全部图表初始展示最新端，隐藏横向滚动条但保留滑动和键盘操作；不显示月份导航或“回到最新”。
- 赞赏区左侧说明与右侧颜文字组成整区切换按钮，邮箱保持独立链接；不显示“赞助清单／收起”文字标签。说明三段 `margin:0`、行高 `1.8`；颜文字字号 `40–76px`，摆动跨度 `18px`。悬停或聚焦时标题显示蓝色字形光，颜文字显示蓝色背光；切换后展示按金额降序的名单，每个名字前为34px Minecraft 方形头像，渲染皮肤外层，预载并解码后才展开，超时或失败回退首字。6人起分两列，580px及以下单列；空名单不显示展开按钮。后台复用无边框操作按钮、保存反馈与确认框。
- 公开页页脚同一行显示 SamsBlog、检测成功后的延迟、签名与版本、RSS、管理；两侧等宽，签名与版本号整体居中。320px及以下隐藏 SamsBlog 与延迟，将空间留给其余内容。签名沿独立中心笔迹书写后让出版本位置，保持1秒书写；不添加琴弦；后台不显示签名。RSS 弹窗支持复制和直接打开 XML，成功反馈与代码复制共用粉色样式。
- 后台使用原生 DOM、独立分区页面与右侧编辑抽屉，手机抽屉占满屏幕，固定标题与正文滚动分开，聚焦输入不被遮挡；沿用艺术字体、主题色、无边框操作与共享动效时长。确认框默认聚焦取消，支持 Escape 与焦点恢复。404 使用独立满屏布局，短内容页脚贴底，长内容自然滚动。

## 动效与无障碍

- Hero 使用 `cubic-bezier(.22,1,.36,1)`，原生滚动时间线控制字标轻退场，不拦截滚动。区块淡入、卡片错峰和短标题逐字渐入仅首次播放；日期或封面先出现，文字稍后接入，更新节点只入场一次。字标短促回弹，按钮按压和搜索展开复用现有动效层级，不增加持续渲染。共享脚本负责首帧主题和封面绑定。
- 动效参数由 `src/config/site.ts` 校验；粒子、星座与点击反馈由 `AmbientScene` 管理。暂停、系统减少动效和页面隐藏时停止持续装饰；内容保持完整。
- 首页背景复用现有光晕，进入项目区偏蓝、内容区偏粉；触发后以1100ms非线性过渡完成，不将颜色进度绑定滚轮步长，不额外启动持续绘制。
- 局部回弹使用共用 `--ease-spring`，仅用于字标、菜单和小标记，不带动导航按钮本体。搜索入口原位切换文案，手机筛选以网格高度展开与收束；反馈先于内容重排。复制成功保留粉色文案并显示小勾，不另弹通知。浮层从触发位置轻微展开，连续切换日期不延迟、不重复入场。
- 逐字文案让读屏读取完整消息。菜单支持 Escape、外部点击、滚动和失焦关闭；对话框提供焦点进入与恢复。
- 保留跳到主要内容入口、清楚的键盘焦点、滚轮／触摸／键盘滚动；贡献图每图一个 Tab 入口，方向键浏览。触摸设备避免粘滞 Hover。
- 贡献图与公开页说明浮层允许鼠标移入阅读；离开触发器和浮层后按配置延迟关闭，键盘焦点优先。Escape 与外部点击立即关闭；悬停提示随滚动关闭，键盘提示在聚焦滚动中更新位置。
- 44px 是按钮点击范围的设计目标，验收时逐项检查，不代表现有所有控件均已达到。

## 验收清单

使用隔离数据，不向正式数据库写示例内容。以下是检查项，不代表本次已全部验证。

1. 320／390／768／1280px、深浅主题、长标题与长文本：无横向溢出，页脚与菜单可用，手机筛选默认收起，摘要、展开与收起均可操作。
2. 键盘与读屏：跳过链接、导航、图表、复制反馈、RSS 和图片对话框；确认 Escape、焦点恢复与名称准确。
3. 长文：重复标题目录、原样代码复制、代码换行、图片缩放；普通图片链接保留导航；主动恢复阅读位置。
4. 文章筛选后进入封面，点击目录再返回：筛选、封面路径和滚动位置保留；不支持转场时正常导航。
5. 手机图表初始在最新端、按月跳转；留言软键盘、中文组合输入与提交期间继续编辑不丢失内容。
6. 暂停、系统减少动效、页面隐藏及触摸：内容完整、操作可达、装饰停止；检查赞赏整区切换与独立邮箱。

- 浅色右侧导航的静态与活动竖线使用可辨识的蓝绿色，远处标记保持不透明，线身与浅色背景对比至少 3:1；扩散光保持独立浅蓝变量。项目标题悬停使用独立字色与浅蓝光晕。动效开关提示沿用左侧联系方式的宽度展开与透明度过渡；暂停和减少动效时直接展示。

- Hero 字标在深浅主题下复用同一套深蓝厚度阴影与背光，不跟随浅色全局光效色板变化。

- 文章评论使用纸面输入与短手绘光标，昵称与邮箱记忆及回复通知默认勾选，取消记忆后保持该选择；透明手绘方框与文字同行，整行点击不选中文字，对勾按笔迹绘入，空邮箱不订阅通知；邮箱不公开。长代码默认折叠，文件名与复制／换行／展开位于吸顶工具条，局部滚动不产生页面横向溢出。

- Hero 中央字标悬停不位移。项目名称单独响应悬停与键盘聚焦，字形背光从左向右渐亮，退出反向收回；长文封面向正文的羽化范围更宽，仍裁切在卡片内。
- 友链申请最大宽度1200px，顶部为本站资料：桌面左侧首页截图，右侧三列紧凑资料，支持单项和全部复制，成功显示粉色反馈；窄屏收为单列。标题使用24px艺术字，收紧上下间距。桌面六项输入分为两行三列，一句话介绍为单行，与联系邮箱同排；窄屏单列。沿用艺术字体与手绘光标，输入不出现聚焦外框，以标签颜色和纸面色变化提示焦点；背景中心为实色纸面，仅圆角外围一圈柔和虚化，文字不模糊；进入与退出以非线性位移和虚化衔接，关闭按钮与送出申请并排放在底部。关闭保留草稿，点击周围退出。后台创建、保存操作共用无外框文字按钮，移除旧渐变按钮样式。
