# 视觉与交互规范

沿用夏日插画与粉蓝米配色。变量集中在 `src/styles/global.css` 的 `:root`，沿 `--bg/--surface/--text/--line/--ease-out` 命名。

- 区块英文标题使用单个词，文章区为 `ARTICLES`，阅读页省去额外英文眉题。
- 首页 `PROJECTS`、`ARTICLES`、`GUESTBOOK`、`FRIENDS` 分别使用橙、蓝、粉、绿主题色；中文区块标题为“留言纸条”“网站友链”，右侧导航使用“留言”，文章入口随有文章时显示。
- 全站复用 `--playful` 艺术字体栈，不下载字体。保持导航、正文、表单、统计与后台的统一字号层级。
- 首页：Hero → 项目展示 → 最新两篇文章（有内容时） → 留言 → 友链 → 统计。Hero 中央蓝白字标保留厚度阴影和柔光，底部120–220px渐变衔接正文。
- 桌面项目双列、留言双列、统计四列；手机分别单列、单列、两列。友链背景减淡、虚化、四周羽化，深浅主题遮罩保证文字可读。
- 悬停项目时名称变为蓝色并沿字形添加清晰光晕，项目整体轻微偏移并非线性回弹，不给容器加光圈。文章文字跳转采用更大字号，搭配带轻微回弹的位移与箭头，不加下划线；键盘聚焦同样响应，减少动效时关闭运动。
- 留言区保留纸条、胶带与折角；失败保留输入，成功清空。手绘光标不能影响输入法、选区或键盘操作。
- 文章卡片不设外框，沿用粉蓝标签，始终纵向单列；首图按可见顺序左右交替、保留圆角，与正文留出间距；图片朝正文方向渐隐并向外柔和虚化，悬停缩放不得超出组件圆角；外层保留 GitHub 日期提示同款柔和背光；首页呈现最新两篇。关于页右侧竖排排序、来源与分类点击栏，手机端三组紧凑排列于列表上方。筛选控件与阅读正文均使用现有艺术字体，文章后台大屏双栏写作/预览、窄屏上下排列。空状态不填充示例内容，顶部导航不增加文章。
- 关于页联系区桌面四列、中屏两列、手机单列。右侧复用首页区块导航，包含联系、文章、痕迹和赞赏，沿用定位高亮、光晕扩散、悬停疏密与艺术字体；手机隐藏。文章卡片压缩上下留白，摘要两行。痕迹第一行 GitHub，第二行 GPT/DeepSeek，窄屏单列；图表内部保留横向滚动和即时详情；GitHub/Token 提示宽300px，窄屏不超出屏幕。
- 文章后台类型菜单与确认框沿用主题表面、粉蓝色和艺术字；确认框默认聚焦取消，支持 Escape 和焦点恢复，不使用原生 confirm。
- 公共按钮以文字/图标为主，保留44px点击范围与清楚的键盘焦点。手机菜单支持外部点击、滚动、失焦和 Escape 关闭，不锁定页面。
- 页面滚动条隐藏，保留滚轮、触摸与键盘滚动。跳到主要内容链接必须可聚焦；贡献图每图一个 Tab 入口，方向键浏览。
- 公开页页脚同一行居中放置小号 `SuperSam` 手写 SVG 签名，与左侧 SamsBlog 垂直对齐；使用圆润粗笔画字形，r 和第二个 S 靠近但断笔；每笔使用独立的中心路径，按字母从左到右、按笔顺以整体慢—快—慢的节奏在1秒内依次写完，不沿字体轮廓扫描。主题配色跟随正文，暂停及减少动效时显示静态完整签名。后台不显示，不增加第三方依赖。书写结束后签名非线性左移，右侧逐字淡入项目实际版本号（自动读取 `package.json`），完整落款组居中；手机端缩小 SamsBlog 与签名，和 RSS、管理保持同一行，Hover 显示柔和蓝色背光。暂停或减少动效时直接显示完整落款，收束与逐字动画时长由签名配置校验。
- Hero 渐入使用 `cubic-bezier(.22,1,.36,1)`；滚动渐显、光晕、粒子及点击反馈集中于 `AmbientScene`。可暂停，遵循 `prefers-reduced-motion`，页面隐藏时暂停；后台静态。
- 动效数量和倾斜角度在 `src/config/site.ts` 校验；保持桌面60/手机18粒子，使用60个不同的定位点，倾斜2.5°上限3°，不继续叠加漂浮按钮、卡片弹跳或玻璃拟态。

改动后检查320/390/768/1280px、深浅主题、菜单和焦点、长文本、无横向溢出、减少动效与图表详情。功能、配置及部署说明统一维护在根 README。

关键回归场景保留以下五组，使用隔离数据，不向正式数据库写示例内容：

1. 320px 页脚单行、菜单展开／关闭、RSS 说明与 Escape 回焦点；检查长标题和文章筛选收起态。
2. 长文重复标题目录、原样代码复制及粉色成功反馈、代码换行、图片放大与键盘关闭、主动恢复阅读位置。
3. 筛选／排序后进入封面，点目录再返回，确认筛选、封面路径和滚动位置保留；进入舒展、返回更快。
4. 手机贡献图初始在最新端，按月前后跳转；留言软键盘及中文组合输入不丢选区、提示高度平滑变化。
5. 深浅主题圆形切换不移位；触摸无粘滞 Hover，暂停及系统减少动效下内容完整、操作可达。

- 公开页滚动动效分为区块淡入、卡片错峰、短标题逐字轻弹三层，使用统一非线性缓动；仅首次进入播放，保留原有 Hover 位移，暂停及减少动效时立即完整显示。页脚移除品牌头像，版本号用淡辅助色。

- 友链链环改为可配置的 RSS 入口，沿用艺术字体与主题色，悬停时波纹展开、非线性轻移和背光；留空时隐藏，键盘可单独聚焦，尊重暂停和减少动效。移除书签与回形针；背景每隔数秒随机抽选相邻粒子连接，两层星图平滑交替淡入淡出。限制连线长度、点数与分叉密度，保持现有粒子数量；暂停、减少动效及页面隐藏时停止重选。

- 后台复用右侧竖线导航，顶栏仅动效按钮展开说明；友链 Hover 显示主题色背光，联系方式的背光跟随各组件配色；统计面板数字首次可见时慢起、加速、慢收。

- 项目关键词采用与编号同色、等粗的手写双横线，连笔转折接近“2”，仅 Hover／键盘聚焦时沿路径非线性绘制、离开时按下横线、连笔、上横线反向收回，不淡出；不恢复已删除的椭圆、书签或回形针。
- 文章排序复用 Web Animations，封面使用浏览器原生跨页转场，返回保留筛选与位置；留言与标题共用逐字渐入，读屏只读完整消息。所有新增动效遵守暂停和减少动效偏好。
