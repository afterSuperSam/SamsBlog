# 视觉与交互规范

沿用夏日插画与粉蓝米配色。变量集中在 `src/styles/global.css` 的 `:root`，沿 `--bg/--surface/--text/--line/--ease-out` 命名。

- 区块英文标题使用单个词，文章区为 `ARTICLES`，阅读页省去额外英文眉题。
- 首页 `PROJECTS`、`ARTICLES`、`GUESTBOOK`、`FRIENDS` 分别使用橙、蓝、粉、绿主题色；中文区块标题为“留言纸条”“网站友链”，右侧导航使用“留言”，文章入口随有文章时显示。
- 全站复用 `--playful` 艺术字体栈，不下载字体。保持导航、正文、表单、统计与后台的统一字号层级。
- 首页：Hero → 项目展示 → 最新两篇文章（有内容时） → 留言 → 友链 → 统计。Hero 中央蓝白字标保留厚度阴影和柔光，底部120–220px渐变衔接正文。
- 桌面项目双列、留言双列、统计四列；手机分别单列、单列、两列。友链背景减淡、虚化、四周羽化，深浅主题遮罩保证文字可读。
- 留言区保留纸条、胶带与折角；失败保留输入，成功清空。手绘光标不能影响输入法、选区或键盘操作。
- 文章卡片不设外框，沿用粉蓝标签，始终纵向单列；首图按可见顺序左右交替、保留圆角，与正文留出间距；图片朝正文方向渐隐并向外柔和虚化，悬停缩放不得超出组件圆角；外层保留 GitHub 日期提示同款柔和背光；首页呈现最新两篇。关于页右侧竖排排序、来源与分类点击栏，手机端三组紧凑排列于列表上方。筛选控件与阅读正文均使用现有艺术字体，文章后台大屏双栏写作/预览、窄屏上下排列。空状态不填充示例内容，顶部导航不增加文章。
- 关于页联系区桌面四列、中屏两列、手机单列。右侧复用首页区块导航，包含联系、文章、痕迹和赞赏，沿用定位高亮、光晕扩散、悬停疏密与艺术字体；手机隐藏。文章卡片压缩上下留白，摘要两行。痕迹第一行 GitHub，第二行 GPT/DeepSeek，窄屏单列；图表内部保留横向滚动和即时详情；GitHub/Token 提示宽300px，窄屏不超出屏幕。
- 文章后台类型菜单与确认框沿用主题表面、粉蓝色和艺术字；确认框默认聚焦取消，支持 Escape 和焦点恢复，不使用原生 confirm。
- 公共按钮以文字/图标为主，保留44px点击范围与清楚的键盘焦点。手机菜单支持外部点击、滚动、失焦和 Escape 关闭，不锁定页面。
- 页面滚动条隐藏，保留滚轮、触摸与键盘滚动。跳到主要内容链接必须可聚焦；贡献图每图一个 Tab 入口，方向键浏览。
- Hero 渐入使用 `cubic-bezier(.22,1,.36,1)`；滚动渐显、光晕、粒子及点击反馈集中于 `AmbientScene`。可暂停，遵循 `prefers-reduced-motion`，页面隐藏时暂停；后台静态。
- 动效数量和倾斜角度在 `src/config/site.ts` 校验；保持桌面40/手机18粒子、倾斜2.5°上限3°，不继续叠加漂浮按钮、卡片弹跳或玻璃拟态。

改动后检查320/390/768/1280px、深浅主题、菜单和焦点、长文本、无横向溢出、减少动效与图表详情。功能、配置及部署说明统一维护在根 README。
