# 前端视觉规范

沿用部署版的夏日插画与粉蓝米配色。首页顺序：Hero → 我的项目 → 留言 → 友链 → 匿名统计。相册与文章均已退役。

## 页面与样式

- 全站共用 BaseLayout、导航、主题和页脚；设计变量集中在 `global.css`，沿 `--bg/--surface/--text/--line/--ease-out` 命名。
- Hero 使用当前部署版插画，底部渐变向下延伸，以更宽的过渡连接正文背景；站点名称和主要入口位于首屏。
- 首页展示 SamsTownWeb、SamsFlayerBot、SamsBlog；关于页不重复项目模块。
- 公共留言区桌面双列、手机单列，隐藏防垃圾字段；控制图标尺寸，允许长文本换行，保留清楚的提交状态。
- 全站使用系统字体栈，避免网络字体加载替换。保留焦点、手机菜单和减少动效支持。

## 动效与精简

- Hero 非线性渐入、章节滚动渐显；公共光晕、漂浮粒子和入口点击火花集中于 AmbientScene。
- effects 配置桌面28、手机12个粒子，上限40；提供暂停开关，遵循系统减少动效，隐藏页面暂停动画。
- 无客户端框架或粒子依赖；后台保持静态。相册页面、图片管理、数据表、专属测试与素材已删除。
- 只保留页面实际引用的插画、favicon 和站点品牌素材，不建立独立可运行设计样稿。
- 移动端隐藏浏览器滚动条，但保留触摸滚动、键盘焦点与滚动容器的可见边缘提示。

## 参考

[React Bits Particles](https://reactbits.dev/backgrounds/particles)用于稀疏漂浮氛围参考；[Click Spark](https://reactbits.dev/animations/click-spark)用于短促点击反馈。当前通过CSS和原生事件实现，不引入对应框架依赖。

## 当前装饰

- 项目区加入 CSS 纸胶带标签与主题色点，减少动效时取消纸胶带旋转。
- 公开页顶部加入 2px 阅读进度线，用 CSS 变量更新，减少动效时显示静态色线。
- 贡献图区域保留原生横向滚动与键盘访问，窄屏通过滚动容器查看完整年度数据。
- 最近一次 GitHub 公开贡献以无框日期标记展示，客户端本地化日期，数据不可用时隐藏。
- Hero 贴纸增加最大2.5°鼠标倾斜，触摸、键盘、暂停动效和 `prefers-reduced-motion` 下关闭。
- Hero入口、动效开关、联系入口与后台操作按钮去掉外框和整块按钮底色，保留文字、图标、悬停颜色与键盘焦点。表单字段继续保留输入区域。

避免继续增加点击火花、漂浮按钮、卡片弹跳和玻璃拟态层，它们会稀释插画主体并增加移动端负担。
