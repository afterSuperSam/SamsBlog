# 视觉与交互规范

记录当前界面契约；使用、配置与部署见根 README。视觉建议不等于已实施功能。

## 视觉基础

- 沿用夏日插画与粉、蓝、米配色，深浅主题共享字号与间距层级。光效使用独立 `--glow-*` 色板：浅色使用明亮粉蓝与淡杏色，文字继续使用深色强调色；自定义组件色的光效在浅色下混白，深色保持原值。
- 设计变量集中于 `src/styles/global.css` 的 `:root`，沿 `--bg/--surface/--text/--line/--ease-out` 命名；复用 `--playful` 字体栈，不下载新字体。
- 区块英文标题用单个词；正文、表单、统计和后台保持统一可读性。交互以文字、图标、柔和背光和轻微位移为主。
- 复用现有组件与 SVG，不叠加无关装饰或引入视觉依赖。

## 区块契约

- 首页顺序：Hero → 项目 → 最新两篇文章（有内容时）→ 留言 → 友链 → 统计。顶部导航仅首页、关于；桌面右侧为区块导航，手机隐藏。
- Hero 保留蓝白字标、厚度阴影、柔光和底部渐变。项目桌面双列、手机单列；关键词使用同色手写双横线，悬停与键盘聚焦时绘制，离开反向收回。
- 文章卡片纵向单列、无外框，摘要两行，首图按可见顺序左右交替并朝正文渐隐。关于页提供排序、来源、分类；手机默认显示当前选择摘要，点击展开完整选项。筛选保存在 URL；阅读返回保留来源和位置。
- 阅读页提供目录、代码复制与换行、图片对话框和主动恢复位置；无封面正常跳转，支持的浏览器使用原生跨页封面转场。
- 留言保留纸条、胶带与折角，列表内部滚动，底部渐隐随滚动解除。失败保留输入；成功仅清空仍等于本次提交值且未处于输入法组合中的字段，保留等待期间的新输入。
- 友链背景减淡、虚化和羽化；名称后先日期、再 RSS，日期是不可点击的纯文本，仅 RSS 打开订阅地址，不展开文章、无箭头。缩小上下留白，窄屏允许自然换行；缺失日期仅显示 RSS。
- 关于页联系区桌面四列、中屏两列、手机单列。痕迹第一行 GitHub，第二行 GPT/DeepSeek，窄屏单列；全部图表初始展示最新端，Token 图支持按月浏览。
- 赞赏区左侧说明与右侧颜文字组成整区切换按钮，邮箱保持独立链接；不显示“赞助清单／收起”文字标签。说明三段 `margin:0`、行高 `1.8`；颜文字字号 `40–76px`，摆动跨度 `18px`。悬停或聚焦时标题显示蓝色字形光，颜文字显示蓝色背光；切换后展示按金额排序的名单。
- 公开页页脚同一行显示 SamsBlog、检测成功后的延迟、签名与版本、萌备、RSS、管理；平板采用自适应列宽，避免延迟与签名重叠。320px及以下隐藏 SamsBlog 与延迟，将空间留给其余内容。签名沿独立中心笔迹书写后让出版本位置；后台不显示签名。RSS 弹窗支持复制和直接打开 XML，成功反馈与代码复制共用粉色样式。
- 后台使用原生 DOM、右侧区块导航和主题控件；确认框默认聚焦取消，支持 Escape 与焦点恢复。404 使用独立满屏布局，短内容页脚贴底，长内容自然滚动。

## 动效与无障碍

- Hero 使用 `cubic-bezier(.22,1,.36,1)`；区块淡入、卡片错峰和短标题逐字渐入仅首次播放。共享脚本负责首帧主题和封面绑定。
- 动效参数由 `src/config/site.ts` 校验；粒子、星座与点击反馈由 `AmbientScene` 管理。暂停、系统减少动效和页面隐藏时停止持续装饰；内容保持完整。
- 逐字文案让读屏读取完整消息。菜单支持 Escape、外部点击、滚动和失焦关闭；对话框提供焦点进入与恢复。
- 保留跳到主要内容入口、清楚的键盘焦点、滚轮／触摸／键盘滚动；贡献图每图一个 Tab 入口，方向键浏览。触摸设备避免粘滞 Hover。
- 44px 是按钮点击范围的设计目标，验收时逐项检查，不代表现有所有控件均已达到。

## 验收清单

使用隔离数据，不向正式数据库写示例内容。以下是检查项，不代表本次已全部验证。

1. 320／390／768／1280px、深浅主题、长标题与长文本：无横向溢出，页脚与菜单可用，手机筛选默认收起，摘要、展开与收起均可操作。
2. 键盘与读屏：跳过链接、导航、图表、复制反馈、RSS 和图片对话框；确认 Escape、焦点恢复与名称准确。
3. 长文：重复标题目录、原样代码复制、代码换行、图片缩放；普通图片链接保留导航；主动恢复阅读位置。
4. 文章筛选后进入封面，点击目录再返回：筛选、封面路径和滚动位置保留；不支持转场时正常导航。
5. 手机图表初始在最新端、按月跳转；留言软键盘、中文组合输入与提交期间继续编辑不丢失内容。
6. 暂停、系统减少动效、页面隐藏及触摸：内容完整、操作可达、装饰停止；检查赞赏整区切换与独立邮箱。

- 浅色右侧导航的静态竖线、活动竖线与扩散光使用独立浅蓝变量；项目标题悬停使用独立字色与浅蓝光晕。动效开关提示沿用左侧联系方式的宽度展开与透明度过渡；暂停和减少动效时直接展示。

- Hero 字标在深浅主题下复用同一套深蓝厚度阴影与背光，不跟随浅色全局光效色板变化。
