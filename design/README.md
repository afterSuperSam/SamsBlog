# 视觉与交互规范

记录当前界面契约；使用、配置与部署见根 README。视觉建议不等于已实施功能。

## 读者界面长期验收

每次修改读者相关视觉前先读本节，并逐项验收。

- 导航“读者”使用普通 `/reader` 链接；未登录显示页内登录，已登录显示账号，不弹出站内登录面板。
- 全部卡片与胶囊使用连续曲率，首帧轮廓就绪后显现，避免先画旧外框再替换。
- 邮箱及其他资料输入连同聚焦态不画矩形外框，复用下划线与手绘竖光标；验证码是明确例外，采用3格 C2 连续曲率轮廓，保留可辨识的键盘焦点。
- 背景克制，不加条纹或装饰渐变。
- 文字清楚、字号够大；复用图标与站内艺术字体，删除冗余提示和无意义箭头。图标与文字分列对齐，胶囊轻影贴合轮廓，悬停与点击反馈适配暂停和减少动效。

## 视觉基础

- 沿用夏日插画与粉、蓝、米配色，深浅主题共享字号与间距层级。深色保留 `:root` 原色板，浅色只在专用覆盖块中提亮画布、纸面及阴影；光效使用独立的清透粉蓝与淡杏 `--glow-*` 色板，不增加强度。友链浅色背光单独取光源色，不混用深文字色；其他自定义组件色在浅色下混白，文字保持可读对比，深色颜色原值不变。背景改为宽范围连续的柔和位置渐变，浅深各沿原粉蓝杏色板，背景装饰光晕减弱25%；仅保留极弱颗粒，不使用水纹环、纤维线或条纹，不覆盖正文和图片，不接收点击或新增持续动画。
- 设计变量集中于 `src/styles/global.css` 的 `:root`，沿 `--bg/--surface/--text/--line/--ease-out` 命名；复用 `--playful` 字体栈，不下载新字体。
- 公开页面统一整页短柔焦退出、清晰淡入；不单独连接首图，不拆导航与正文快照。模糊范围沿用3px，切页时不叠加区块渐入；账号页使用轮廓就绪后的局部显现，跳过原生整页快照。主题水波独立处理，暂停与减少动效跳过转场。
- 区块英文标题用单个词；正文、表单、统计和后台保持统一可读性。交互以文字、图标、柔和背光和轻微位移为主。
- 复用现有组件与 SVG，不叠加无关装饰或引入视觉依赖。

## 区块契约

- 首页顺序：Hero → 项目 → 内容 → 留言 → 友链；网站统计移至关于页完整友链之后，区块导航同步更新，保留首次可见计数动画和实时更新。内容先显示最新一篇长文，下方两列分别为最多两条短记录（含更新节点）与一个精选链接，空组隐藏、手机单列；复用公开卡片，不加外围面板。顶部导航为首页、内容、关于、读者；桌面右侧为区块导航，手机隐藏。
- Hero 保留蓝白字标、厚度阴影、柔光和底部渐变，移除 Scroll Down 提示；插画上方导航使用独立浅色强调，离开首屏后恢复页面主题色，不全局反转媒体文字。项目桌面双列、手机单列；关键词使用同色手写双横线，悬停与键盘聚焦时绘制，离开反向收回。
- 项目背景为87°俯视、无旋转的连续柱阵，柱体贴合、无描边，颜色接近深浅主题背景，两侧保持主要能见度，中间保持柔和明暗，深色模式整体更淡。柱面保持纯色明暗，不使用表面纹理，配色随主题变化。背景层上下各延伸48–96px，沿波峰逐柱进出：滚动约45%入场、10%完整展示、45%退场。两侧提前入场、延后退出，中间更晚出现、更早收回；进入以更强的指数缓动快速升起后放缓，退出按原进度加速收回，窄色带随进退扫过，不使用快速闪烁。上下以大范围错落渐隐和局部模糊融入页面，模糊仅作用于柱阵，文字保持清晰。静止轻微浮动且最多20帧，滚动和进退时最多30帧，连续波浪增强；接近区块才加载 Three.js，暂停／减少动效时静态呈现，离屏／后台停止绘制。
- 内容页文章卡片纵向单列、无外框，摘要两行；长文卡片上下内边距12px，压缩标题、标签与摘要的纵向间隔；首图方向按每篇后台设置，支持左图、右图和纯文字，旧文章默认左图，图片朝正文渐隐。内容标题与文章整体增加顶部留白。标题旁保留小号搜索入口；“全部／归档”放在右侧固定筛选顶部，位于排序、形式与星标之前；搜索在同一行向左展开，只有艺术字体和短手绘光标，无浮层、底板与外框。收起时有关键词则显示红色“取消”，只清空关键词；手机“全部／归档”常显在筛选折叠入口上方，搜索展开不隐藏。桌面右侧筛选固定于浏览器视口，滚动到页顶、中段或页底均保持可见；避开顶部导航和正文，低高度时区域内部可滚动，手机仍在原位折叠，筛选项悬停不位移，移除筛选底部重置按钮；归档按月分组。旧 URL 的来源、分类、标签和年月条件继续生效，列表上方始终显示条件及重置入口，手机折叠不隐藏提示。筛选保存在 URL，阅读返回保留来源和位置。
- 后台 Markdown 正文随输入、载入、插图和可用宽度变化自动增高，删减后缩回；桌面最低420px、手机最低320px，无手动纵向拉伸和正文内部纵向滚动条，长文沿抽屉滚动。后台阅读预览显示题目、来源、分类、标签、日期、首图、目录与正文；首页卡片预览直接复用公开卡片组件。顶部移除“媒体库”快捷按钮，媒体管理与上传入口保留。
- 内容形式使用同一套卡片结构：长文章沿用横向封面，短记录以粉色日期引出文字，简单内容可在摘要区域完整显示时不展示操作，较长记录在日期旁用无边框“展开／收起”原地切换摘要和全文，复用非线性高度动画，正文链接与图片保持可用；键盘可操作，无脚本降级为独立阅读链接，暂停和减少动效直接切换。外部链接使用蓝色域名与紧凑文字，不加左侧竖线，更新为杏色时间节点，日期与正文之间不加竖线。没有外框，沿用柔和背光；展开短记录不随悬停位移，归档仍可从标题索引原地展开。形式选择和外链地址在后台编辑，预览与公开列表同步。
- 外链说明复用短记录展开，按钮沿用外链蓝色，摘要能容纳的简单内容不显示按钮；展开正文中的链接独立可用，标题继续打开外部站点。首页轮换保留同一卡片节点并重置展开状态。
- 星标按钮在后台内容行内，无外框，以描边星形与淡金色区分状态；公开标题仅在字形内呈现金色流光，5.2秒波浪式流光与增强呼吸，浅色用较深金色保证可读性。暂停或减少动效后保持静态，不改变卡片布局与排序。
- 阅读页提供目录、代码复制与换行、图片对话框和主动恢复位置，进入及返回统一使用整页虚化切换。字号18–26px与标准／宽松行距集中在原有工具栏，使用无边框文字按钮和粉色选中反馈，本机记忆并首帧恢复；不受固定启用的舒适阅读影响。图片查看器加载时保留工具栏，失败显示就地重试，关闭和重新请求均清理旧加载。
- 剧透沿用正文解释的圆角折叠行与高度动效，以淡粉提示区别；默认收起，可键盘揭开，禁用脚本仍可使用；不把隐藏内容的标题带进目录，摘要和订阅正文以查看提示代替。
- 留言与评论输入框自动增高到8行，继续保留短手绘光标和原生选区。颜文字入口为无外框文字，可展开精选与本机最近使用；不额外显示快捷键提示。长内容和超过3条的回复以明确文字入口折叠，站长标识复用一份静态签名字形，昵称相同的访客不显示此标识。引用原话在提交前和回复列表中使用淡蓝圆角底，无左侧竖线。
- 首页友链使用循环景深卡组展示全部公开站点：中央清晰大卡，左右卡片后退、缩小、低透明和轻模糊；卡面用本站夏日艺术字体、柔软纸色与极淡边线，不加外围大面板。卡片保持按站点稳定的轻微错角，悬停背光独立渐入渐出；只在卡片下方居中显示计数，收紧上下空白并保留头像与阴影空间。键盘进入卡组时只在计数附近显示小范围粉色焦点提示，不画整块大框。每张唯一卡片保留头像、背景、站名、简介、RSS入口与三态连通文字，最新RSS标题和两行短摘要合入卡内，不显示网址、日期或毫秒，不再保留右侧独立动态。自动播放每张停留2.5秒，再用0.5秒非线性缓动切换下一整张并停稳；停留阶段没有持续帧循环。鼠标拖动、触摸横滑、横向触控板和左右键可切换；滑动期间暂停，悬停不影响计时，键盘操作卡片链接时保护焦点，不阻挡纵向页面滚动。取消拖动选中文字与鼠标点击蓝框，保留键盘focus-visible；暂停、减少动效、离屏和页面后台停止自动切换；暂停或减少动效时手势直接整张切换，窄屏仍可手动访问全部卡片；刷新排除隐藏项，计数随公开卡片同步，无脚本降级为静态卡片。
- 文章正文永久启用舒适阅读，居中且上限860px，不提供退出按钮；1400px以上右侧独立显示分层目录，当前章节以移动的圆角浅蓝底色提示。章节下方细线长度表示相对篇幅，填充表示阅读进度；图片、字体与字号变化后更新。窄屏仍用正文上方折叠目录，不增加可见滚动条。正文19–20px，工具及提示17–18px；阅读按钮有粉色悬停和主题提示。文章默认使用系统字体，保留“切换艺术字体”按钮并记住手动选择。
- 阅读补充解释使用无外框、淡蓝底的折叠行，原生 details 渐进增强为双向高度动画；旁注使用粉色小标题与轻细引线，1440px以上置于页边，窄屏回到正文流。正文引用使用无竖线的圆角淡色底块，右上角提供“摘录成卡”，直接摘取引用正文，沿用当前主题与艺术字体，PNG 背景复用页面的蓝粉边缘主题光晕，浅色保持明亮中心，深色压低色光，落款使用导航字标图片，正文下方装饰减淡，不叠加噪点或纹理；弹窗支持 Escape 与焦点恢复。
- 首页“换一条”与精选链接标题同行，依次循环公开链接，始终只占一张卡片；不自动轮播。内容页 CONTENT 标题下方保留本机阅读路径，最多两条，标题悬停变色双向过渡，无记录时整行隐藏；移除清除按钮，保留已有本机记录和同步。首页移除“最近写下”可见抬头与“之前读到”阅读路径，保留内容区语义标题及原有卡片。
- 导航字标的蓝、绿、金、粉、紫虹彩只覆盖已有字形，透明度0.38，不用叠亮混合，停留时微倾斜；不扩张导航高度，无持续帧循环。站内链接与友链无悬停预览。
- 留言保留纸条、胶带与折角，列表内部滚动，底部渐隐随滚动解除。失败保留输入；成功仅清空仍等于本次提交值且未处于输入法组合中的字段，保留等待期间的新输入。清空后播放折纸、收件印记与空白纸条恢复，重新聚焦或输入立即结束装饰动画；暂停与减少动效时直接显示成功文案。
- 友链顺序为星标、推荐、默认、失联，组内按最新 RSS 文章日期倒序，无日期后排、编号稳定；后台推荐与星标独立保存，星标优先。首页卡组轮流展示全部公开友链；“全部友链”跳至关于页完整列表。关于页显示“星标友链／推荐友链／默认友链／失联友链”四组24–30px艺术字体标题，空组显示简短空态；标题与背景光按组使用黄、橘、蓝、灰，深浅主题保持可读对比。有效连通失败归失联，恢复回原标记组；刷新状态和RSS后移动原节点重排，聚焦卡片时延迟到焦点离开。卡片删除网址文字，名称旁只保留RSS按钮，不显示更新时间；连通性仅显示“访问流畅／响应较慢／状态未知”，不显示毫秒。关于页背景虚化、羽化及悬停保持原样，触摸、暂停和减少动效保持原规则。星标名称和星号保留金色波浪；首页独立采用上述景深卡组。
- 关于页联系区桌面四列、中屏两列、手机单列。痕迹桌面同一行依次显示 GitHub、ChatGPT 用量、文章数量，窄屏单列；三张热力图顶端对齐，分别使用蓝、粉、杏色。用量说明只显示截止日期，不显示来源前缀和当日未完提示，既有用量数值不变。全部图表初始展示最新端，隐藏横向滚动条但保留滑动和键盘操作；不显示月份导航或“回到最新”。
- 赞赏区左侧说明与右侧颜文字组成整区切换按钮，邮箱保持独立链接；不显示“赞助清单／收起”文字标签。说明三段 `margin:0`、行高 `1.8`；颜文字字号 `40–76px`，摆动跨度 `18px`。悬停或聚焦时标题显示蓝色字形光，颜文字显示蓝色背光；切换后展示按金额降序的名单，每个名字前为34px Minecraft 方形头像，渲染皮肤外层，预载并解码后才展开，超时或失败回退首字。6人起分两列，580px及以下单列；空名单不显示展开按钮。后台复用无边框操作按钮、保存反馈与确认框。
- 公开页页脚底部留白28px，同一行显示 SamsBlog、检测成功后的延迟、签名与版本、RSS与Status；Status在当前页打开 `https://status.moesam.com`；两侧等宽，签名与版本号整体居中。移除“管理”文字入口，SuperSam 手写签名链接到 `/admin`，保留至少44px点击范围和键盘焦点提示。320px及以下隐藏 SamsBlog 与延迟，将空间留给其余内容。签名沿独立中心笔迹书写后让出版本位置，保持1秒书写；不添加琴弦；后台不显示签名。RSS 弹窗支持复制和直接打开 XML，成功反馈与代码复制共用粉色样式。

## 动效与无障碍
